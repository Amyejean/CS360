For this project, I created a weight-tracking app to help users keep track of their weight and progress toward their goals. I wanted the app to be simple and easy to use so people could enter their information without getting confused.

The app included a login screen, registration, and screens for entering and viewing weight information. I tried to keep the design simple with clear buttons and easy navigation. My goal was to make everything easy for users to find.

When coding the app, I worked on one part at a time using Android Studio, Java, and XML. I learned that breaking the project into smaller steps made it easier to find and fix problems. I would use this same approach in future projects.

I tested my app using the Android Studio emulator. I checked the screens, buttons, and features to make sure they worked correctly. Testing helped me find issues with the layout, missing text, and permissions. It also showed me how important testing is before finishing an app.

One of my biggest challenges was getting the screens to display correctly. Some text was missing, and certain features were not working. I had to adjust the layout constraints, review my code, and try different solutions until I made progress.

I think my biggest success was learning how to build and improve the app's user interface. Even though I struggled with parts of the project, I learned a lot about coding, troubleshooting, and designing mobile apps. Overall, this project helped me become more comfortable using Android Studio and gave me skills I can use in future projects.
